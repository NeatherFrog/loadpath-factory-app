# RetroDrop Dashboard

Десктоп-приложение для охоты за эирдропами в секторе перп-DEX. Что внутри:

- **Исследование.** Скоринг проектов по 8 критериям: команда, инвесторы, объёмы, апсайд дропа, доступность поинтов, API, цена фарма, риски.
- **Рынки.** Спреды и фандинг на Variational, Nado и Hyperliquid в реальном времени; поиск самых дешёвых рынков и фандинг-арбитража.
- **Дельта-нейтральный бот.** Набивает объём (и поинты) на Nado, хеджируя позицию на Hyperliquid. Есть бумажный режим на живых стаканах.
- **Автохедж ручных сделок на Variational Omni.** Торгового API у Omni нет: позицию открываешь руками, а приложение сразу открывает обратную на Nado или Hyperliquid.
- **Поинты & OTC.** Калькулятор стоимости поинта по FDV-сценариям, сравнение с OTC-оффером, точка окупаемости фарма, список площадок и чек-лист безопасной сделки.
- **Автообновление.** Новая версия скачивается сама и ставится при перезапуске.

Почему выбраны Variational и Nado — см. [docs/RESEARCH.md](docs/RESEARCH.md).

## Установка (Windows)

1. Открой [Releases](https://github.com/NeatherFrog/loadpath-factory-app/releases/latest) и скачай `RetroDrop-Setup-x.y.z.exe`.
2. Запусти. Windows SmartScreen может предупредить о неподписанном приложении: «Подробнее» → «Выполнить в любом случае».
3. Ярлык появится на рабочем столе.

## Как работают обновления

| Что меняется | Как доходит до тебя |
| --- | --- |
| Код приложения (бот, интерфейс) | Push в `main` с новой `version` в `package.json` → GitHub Actions собирает установщик и публикует Release → приложение скачивает его в фоне (проверка при запуске и каждые 30 мин) → кнопка «Обновить» в левом нижнем углу или установка при следующем закрытии. |
| Данные исследования (`data/projects.json`) | Push в `main` → приложение подтягивает файл с GitHub при запуске и каждые 30 мин. Переустанавливать ничего не нужно. |

## Бот: как начать

1. **Бумажный режим** (по умолчанию). Ключи не нужны: бот берёт реальные стаканы Nado и Hyperliquid, а сделки симулирует. Запусти его на час и посмотри объём и цену фарма за $1M.
2. **Ключи** (вкладка «Настройки»):
   - Nado: адрес кошелька и ключ **linked signer** (1-Click Trading). Этот ключ торгует, и его можно отозвать.
   - Hyperliquid: адрес аккаунта и ключ **API Wallet** (More → API). Он торгует, но не выводит средства.
   - Ключи шифруются системным хранилищем ОС (DPAPI / Keychain) и никуда не отправляются.
3. **LIVE.** Начни с маленького объёма ($100–200 на ногу) и лимита убытка на день.

### Защиты в боте
- Мейкер-режим (по умолчанию): на Nado ставится post-only ордер, комиссия 1 bp вместо 3.5. Каждое исполнение сразу хеджируется на Hyperliquid.
- Хеджируется ровно исполненный объём ноги A. Если хедж не прошёл после 4 попыток с растущим проскальзыванием, нога A откатывается.
- Каждые 30 с идёт проверка дельты; расхождение больше допуска выравнивается.
- Цикл не открывается, если спред или расхождение цен между биржами больше лимита.
- Есть дневной лимит убытка и дневная цель по объёму.
- «Остановить» закрывает текущий цикл, «Закрыть всё» закрывает все позиции бота маркетом.
- Пока бот работает, компьютер не засыпает.

## Разработка

```bash
npm install
npm run dev        # Vite + Electron с hot reload
npm test           # unit-тесты движка и расчётов
npm run typecheck
npm run dist       # локальная сборка установщика в release/
```

Структура:

```
src/main/          Electron main: IPC, хранилище, автообновление
src/main/bot/      движок дельта-нейтрала + адаптеры бирж (nado, hyperliquid, paper)
src/main/data/     публичные API Variational / Nado / Hyperliquid
src/renderer/      React-интерфейс
src/shared/        общие типы, скоринг, оценка поинтов
data/projects.json исследование (обновляется без релиза)
```

`index.html`, `privacy.html`, `usage.html` и `style.css` в корне — это старые публичные страницы AXIS Video Factory (GitHub Pages). К приложению они не относятся и оставлены, чтобы не сломать ссылку на политику конфиденциальности.

## Выпуск обновления

1. Внести изменения, поднять `version` в `package.json` (например, 0.1.1 → 0.1.2) и описать изменения в `RELEASE_NOTES.md`.
2. Push в `main`.
3. Workflow **CI & Release** проверит код, соберёт `RetroDrop-Setup-0.1.1.exe` и опубликует Release, после чего приложения у пользователей обновятся сами.

> Риски: фарм поинтов — это ставка на будущий токен. Поинты могут обнулить за «неорганическую» активность, TGE может сдвинуться, а FDV оказаться ниже ожиданий. Бот не гарантирует прибыль: комиссии и спред платятся всегда.
