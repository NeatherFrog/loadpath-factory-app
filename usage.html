Operator-controlled production

The desktop application is for its operator’s own channel. It is not offered as a public hosted service. The operator chooses the API provider, spending ceiling, production switch, upload switch and requested visibility.

Publication and responsibility

Generated media must respect third-party rights and applicable platform rules. Automated factual and media checks can miss errors. A successful upload does not guarantee public visibility, audience engagement, monetization or revenue. The operator remains responsible for material published through the connected channel.

The YouTube integration is subject to YouTube’s Terms of Service. OAuth consent, API project verification and platform quotas can affect availability. This application is not affiliated with or endorsed by Google, YouTube or Blender.

Stopping and disconnecting

Use the desktop production and upload switches to stop new work. Existing accepted media and progress receipts remain local so work can resume. Google access can be revoked from the operator’s account; see the privacy policy for storage and deletion details.
