Privacy &
data use.

This policy describes the AXIS Video Factory private Windows application, also displayed as LOADPATH FACTORY, operated for its owner’s YouTube production workflow.

Data accessed and purpose

When the operator authorizes Google access, the application receives OAuth access and refresh tokens. It reads the connected YouTube channel’s identifier and title to confirm the destination. It uploads the operator’s accepted video, title, description, tags and thumbnail, then reads the uploaded video’s identifier, channel and visibility to confirm the result. These features use the youtube.upload and youtube.readonly scopes.

The application does not request Gmail, contacts, Drive, payment information or a Google password. Google handles sign-in and consent.

Storage and retention

OAuth tokens and resumable upload session information are stored on the operator’s Windows computer, encrypted using Windows Data Protection API. Channel details, upload status, generated media, API usage records and diagnostic logs are also kept locally. They remain until the operator removes them; stopping production or revoking Google access does not automatically delete local files or uploaded YouTube videos.

Sharing and external services

Authorized video content and publishing metadata are sent to YouTube over HTTPS. Google credentials and channel authorization are not sent to the script-generation provider. The separately configured AI provider receives production prompts, reference material and media samples needed for authoring or review; that service is distinct from Google authorization. Local Blender rendering and local speech synthesis do not require sending Google user data to an AI provider.

Google user data is used for the visible channel-connection and publishing features. It is not sold, used for advertising profiles or used to train general-purpose AI models by this application. Its use of Google user data follows the Google API Services User Data Policy, including the Limited Use requirements. This statement does not represent Google certification.

Control, revocation and deletion

The operator can disable automatic uploads and production in the desktop interface, and revoke the application’s access using Google Account permissions. Uploaded videos can be managed or deleted in YouTube Studio. To remove local authorization records and cached Google data, stop the application and remove its YouTube authorization directory from the local runtime; the operator should retain any media they wish to keep. Contact the maintainer for assistance before deleting unfamiliar files.

This website and contact

This informational website has no application sign-in, trackers, analytics scripts or upload forms. GitHub Pages provides the hosting and may process ordinary request information according to GitHub’s privacy statement. YouTube’s processing is described in Google’s privacy policy.

Application and privacy questions can be raised with the operator through the project contact page. Do not post passwords, tokens, personal data or private media in a public issue.
