AXIS Video Factory is the application behind the LOADPATH FACTORY desktop interface. It prepares source-based educational films, renders original 3D scenes with Blender, and can upload accepted films to the operator’s connected YouTube channel.

A tool for its channel operator

This is an informational website for a private Windows application, not a public video-generation service. It does not host the desktop interface or accept uploads. Production reliability is still being evaluated; automated checks are not a guarantee of accuracy, artistic quality or revenue.

Why connect YouTube?

The application uses the YouTube Data API to identify the authorized channel, upload videos and thumbnails, and verify the destination and effective video visibility. It requests upload and read-only YouTube permissions. The operator can stop uploads locally or revoke access in their Google Account.
